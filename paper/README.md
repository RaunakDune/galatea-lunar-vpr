# Paper source

- `main.tex` is the manuscript (IEEEtran journal format, 10 pages) and `supplement.tex` holds the proofs,
  two additional experiments and the robustness study (camera roll, pitch and viewpoint; Section SII).
  `main.pdf` and `supplement.pdf` are the compiled versions.
- `numbers.tex` and `tab_*.tex` are **generated** by `src/make_tables.py`. Do not edit them by hand. Experimental
  numbers in the text come from these macros; a few rounded ranges in the prose (e.g. "11–19 points") summarise them.
- `figures/percond.pdf` is generated by `src/plot_percond.py`, and `figures/robustness.pdf` by
  `src/robust_plot.py` from `results/robust/summary.json` (see `docs/ROBUSTNESS.md`).
- Set `\realdatatrue` in `main.tex` to include a real-imagery evaluation subsection.

To build: `latexmk -pdf main.tex && latexmk -pdf supplement.tex`. This requires the `IEEEtran` class. The
supplement takes its cross-references from `main.aux` (package `xr`); the included `latexmkrc` builds
`main.tex` first if needed. On Overleaf, upload the folder as a project, compile `main.tex`, then set
`supplement.tex` as the main document to compile the supplement.
