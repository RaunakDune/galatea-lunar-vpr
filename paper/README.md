# Paper source

- `main.tex` is the manuscript (IEEEtran journal format, 10 pages) and `supplement.tex` holds the proofs,
  additional experiments (learning-rate sweep, reproduction, ablation table, run time), the robustness study
  (camera roll, pitch and viewpoint), the real-imagery protocols, the stage-2 extensions (CLIPPER, 3-D structure,
  Apollo re-ranking) and the second simulator, metric pose and boulder tests.
  `main.pdf` and `supplement.pdf` are the compiled versions.
- `numbers.tex` and `tab_*.tex` are **generated** by `src/make_tables.py`. Do not edit them by hand. Experimental
  numbers in the text come from these macros; a few rounded ranges in the prose (e.g. "11–19 points") summarise them.
- `figures/percond.pdf` is generated by `src/plot_percond.py`, and `figures/robustness.pdf` by
  `src/robust_plot.py` from `results/robust/summary.json` (see `docs/ROBUSTNESS.md`).
- `numbers_apollo.tex`, `tab_real.tex` and `tab_real_ci.tex` are generated by `src/apollo/make_apollo_tables.py`
  from `results/apollo/` (see `docs/APOLLO.md`).
- `numbers_stage2.tex`, `tab_rerank.tex` (which replaces the version written by `make_tables.py`) and
  `tab_stage2_supp.tex` are generated by `src/make_tables_stage2.py` from `results/{rerank_summary,clipper_summary,
  fgw3d_summary,fgw3d_diag}.json` and `results/apollo/apollo_rerank_summary.json`. Run it after `make_tables.py`.
- `numbers_ext.tex` and `tab_ext_supp.tex` (second simulator, metric pose, boulders) are generated by
  `src/make_tables_ext.py` from `results/lunarloc/`, `results/pose_summary.json` and the Apollo re-ranking summary.

To build: `latexmk -pdf main.tex && latexmk -pdf supplement.tex`. This requires the `IEEEtran` class. The
supplement takes its cross-references from `main.aux` (package `xr`); the included `latexmkrc` builds
`main.tex` first if needed. On Overleaf, upload the folder as a project, compile `main.tex`, then set
`supplement.tex` as the main document to compile the supplement.
