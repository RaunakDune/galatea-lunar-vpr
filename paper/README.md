# Paper source

- `main.tex` is the manuscript (IEEE RA-L format, 8 pages) and `supplement.tex` holds the proofs.
  `main.pdf` and `supplement.pdf` are the compiled versions.
- `numbers.tex` and `tab_*.tex` are **generated** by `src/make_tables.py`. Do not edit them by hand. Every
  number in the text comes from these macros.
- `figures/percond.pdf` is generated by `src/plot_percond.py`.
- Set `\realdatatrue` in `main.tex` to include a real-imagery evaluation subsection.

To build: `latexmk -pdf main.tex && latexmk -pdf supplement.tex`. This requires the `IEEEtran` class and
`main.aux` for the supplement's cross-references.
